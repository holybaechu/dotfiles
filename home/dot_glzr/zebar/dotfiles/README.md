# Zebar bar

Based on the [Zebar v3.3.1 Komorebi starter](https://github.com/glzr-io/zebar/tree/v3.3.1/resources/starter), licensed under GPL-3.0 (see LICENSE.md).

Edit `index.html` for widgets and behavior, `styles.css` for appearance, and `zpack.json` for placement. This starter uses CDN-hosted React, Babel, Zebar, and icon fonts, so its first load needs an internet connection. No build command is needed.

The bar reserves 40 logical pixels at the top of each monitor, scaled by Windows display scaling. Workspace buttons use `komorebic focus-named-workspace`; keep workspace names unique across monitors.
