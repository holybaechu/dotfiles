# Dotfiles

Windows desktop and Arch WSL2 configuration, managed with [chezmoi](https://www.chezmoi.io/).

Bootstrap changes Windows settings and removes apps, including Edge and OneDrive.
Review [Setup](docs/setup.md) before running it.
